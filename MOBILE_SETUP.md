# iPhone setup

1. Deploy this project to a public HTTPS Python host.
2. Open the HTTPS URL in Safari on iPhone.
3. Tap Share -> Add to Home Screen.
4. Open AI Signals from the Home Screen.
5. Select Source -> Market -> Symbol -> Timeframe.
6. Wait for REAL FEED STATUS to show LIVE and a recent data age.
7. Review the SMC confirmations and chart levels.

AUTO TRADE is OFF. Do not put private API keys into the iPhone frontend.
